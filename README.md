# AI Resume Matcher

An AI/ML-powered resume-job match analyzer that extracts text from a resume PDF, compares it with a job description, and returns a match score, matched skills, missing skills, and recommendations.

## Features
- PDF resume text extraction
- TF-IDF + cosine similarity
- Technical skill extraction
- Matched and missing skills
- Weighted final match score

## Tech Stack
- Python
- FastAPI
- scikit-learn
- pypdf
